# POST /v1/auth/password

2FA-пароль (после `password_required`).

> Вход с 2FA нельзя завершить без пароля — его передаёте **вы** этим запросом (собираете у
> пользователя и отправляете в поле `password`). Автоматически он не подставляется. Пока пароль
> не отправлен, статус остаётся `password_required`, и вход не завершается.

**Запрос**

```json
{ "session_id": "<32hex>", "password": "пароль-2fa" }
```

**Ответ**

```json
{ "ok": true, "status": "success", "balance": 42 }   // аккаунт — в вашей панели; balance = ваши успешные авторизации
{ "ok": false, "error": "wrong_password" }
```

`wrong_password` (400) — сессия жива, повтор возможен.
