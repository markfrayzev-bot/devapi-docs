# GET /v1/balance

Баланс ключа: число успешных авторизаций и текущие лимиты.

**Ответ**

```json
{
  "ok": true,
  "balance": 128,
  "quota_daily": 0,
  "rate_per_min": 30,
  "sends_today": 17
}
```

* `balance` — число успешных авторизаций по ключу.
* `quota_daily` — суточный лимит отправок; `0` = без лимита.
* `sends_today` — отправок за сегодня.
