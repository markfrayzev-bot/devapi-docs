# Частые ошибки

Ошибки приходят телом `{"ok":false,"error":"<code>","message":"…"}`. Ветвитесь по `error`/`status`, а не по HTTP-коду.

| error | HTTP | Когда | Что делать |
| ----- | ---- | ----- | ---------- |
| `unauthorized` | 401 | Нет/неверный/отозванный ключ | Проверьте `Authorization: Bearer jt_live_…` |
| `bad_phone` | 400 | Номер не в формате E.164 | Отправляйте `+7XXXXXXXXXX` |
| `wrong_code` | 400 | Неверный код | Сессия жива — дайте ввести код заново |
| `wrong_password` | 400 | Неверный 2FA-пароль | Сессия жива — повторите `/v1/auth/password` |
| `rate_limited` | 429 | Слишком часто (лимит/мин на ключ) | Снизьте темп, повторите позже |
| `quota_exceeded` | 429 | Исчерпан суточный лимит отправок (если задан на ключ; по умолчанию лимита нет) | Дождитесь след. суток или снимите лимит ключа |
| `busy` | 429 | Слишком много одновременных сессий ключа | Завершайте/отменяйте сессии, повторите чуть позже |
| `code_limit` | 429 | Слишком много попыток кода | Начните заново с `/v1/auth/phone` |
| `session_expired` | 404/409 | Сессия истекла/не найдена | Начните заново с `/v1/auth/phone` |
| `already_finished` | 409 | Сессия уже завершена | Начните новую сессию |
| `send_failed` | 502 | Код не удалось отправить | Повторите `/v1/auth/phone` позже |
| `upstream_error` | 503 | Временный сбой (транзиент) | Повторите тот же шаг — сессия жива |
| `misconfigured` | 503 | Контур временно недоступен | Повторите позже |
