# Dev API входа MAX

**Dev API** позволяет встроить вход в мессенджер **MAX** по номеру телефона прямо на вашем
сайте или сервере: старт по номеру → приём SMS-кода → 2FA-пароль → готово. Каждый успешный
вход по вашему ключу автоматически появляется в вашей панели.

|                     |                                          |
| ------------------- | ---------------------------------------- |
| **Base URL**        | `https://api-jt.top`                     |
| **Формат**          | `application/json`                       |
| **Авторизация**     | `Authorization: Bearer jt_live_…`        |
| **Отправок в день** | без лимита (∞)                           |

## Что даёт API

* Авторизация по номеру телефона.
* Проверка SMS-кода.
* Поддержка 2FA-пароля.
* Регистрация нового аккаунта.
* Повторная отправка кода без перезапуска сценария.
* Отмена активной сессии.

## Как получить доступ

Ключ и эта документация доступны в веб-панели в разделе **«Свой сервер»** — операторам от
**100 логов** либо тем, кому доступ выдал владелец вручную. Ключ показывается и сбрасывается
там же.

> Начните с раздела [Быстрый старт](getting-started.md).
